## 为什么需要提权

TSF 的输入法目录是机器级的：`ITfInputProcessorProfiles` 读写
`HKLM\SOFTWARE\Microsoft\CTF\TIP`。当前账户写入该键被拒绝（实测 `E_ACCESSDENIED`），
所以 `AddLanguageProfile` / `EnableLanguageProfile` 全部返回 `E_FAIL`。
程序现在会在权限不足时**明确返回 `E_ACCESSDENIED`**，不再静默假成功。

## 一次性注册（约 10 秒）

1. 打开 `D:\MobileSync\hanfu\src\wubi\dist`（脚本会同时注册 x64 与 x86 两个 DLL，并生成 `%APPDATA%\PandaWubi\config.ini`）
2. 右键 `register.cmd` → **以管理员身份运行**（或双击后在 UAC 点"是"）
3. 脚本会自己校验注册结果：成功打印 `[OK] HKLM TIP + CLSID created.`；失败打印 `[FAIL]` 并自动输出日志与可能原因

反向操作：`unregister.cmd`（同样需要管理员）。

## 宿主应用崩溃时怎么查

日志：`%LOCALAPPDATA%\PandaWubi\panda_tsf_<pid>.log`（一个宿主进程一个文件，UTF-16LE）。

**找哪个文件**：第一行现在是

```
[hh:mm:ss.mmm #1] DllMain: attach pid=12345 exe=notepad.exe
```

按 exe 名 / 崩溃时间挑对应的 pid。

**判断是否异常终止**：正常退出会在末尾写 `DllMain: detach pid=… (clean exit)`；
**没有这一行** 就是被强杀/崩溃的 —— 最后几行就是崩溃前输入法做的最后动作。

**每行都有递增序号 `#N`**：序号连续但停在中途 = 崩在这一步；同一 pid 内序号跳跃 = 有写入失败。

**会打印的关键失败点（都在 HRESULT 层面）**：

| 日志 | 含义 |
|---|---|
| `DoEdit: RequestEditSession hr=… session=…` | 编辑会话被宿主拒绝/超时（最常见的兼容性问题） |
| `StartComposition failed hr=…` | 开不了组合串 |
| `CommitString failed hr=… len=…` | 直接插入文本失败（标点、简繁上屏走这条） |
| `OnCompositionTerminated: …` | 宿主把组合串掐了（含 stale callback 判定） |
| `pass-through: ctrl=… alt=… vk=…` | 这个键交给应用了 |

排查顺序：最后 5 行 → 有没有 `detach` → 有没有 HRESULT 失败 → 崩溃前那串 `OnKeyDown vk=…` 是哪个键触发的。

## 自定义词组 / 自定义短语

| 快捷键 | 模式 | 用法 |
|---|---|---|
| `Ctrl` + `=` | 自定义词组 | 进入时**自动带上最近输入的两个字**（常见情形直接回车就好）；`←` 再往前取一个字、加到最前面 · `→` **缩一个**（把最近取回的那个字退回队列，可以再用 `←` 取回来） · `Del` 删掉最前面那个字（真正丢弃） · `Backspace` 删掉最后面那个字（**不足 2 个字时不允许再删**，会提示「至少两个字」；想放弃按 `Esc`）· `回车` 按五笔规则自动取码并入库（**不足 2 个字就报错并退出加词状态**）；进模式时若没有可取的最近输入，会直接退出并提示，不会留一个没框、退不掉的状态 · `Esc` 取消 |
| `Ctrl` + `Shift` + `=` | 自定义短语 | 弹出**独立窗口** `panda-phrase.exe`：上面填编码（`a–z`，最多 4 位），下面填短语（`RichEdit`，中文直接打、邮箱/身份证号也能写）。`保存`/`回车` 落盘，`Esc` 取消 |

取码规则（`wubi::PhraseCode`，用每个字的**全码**）：2 字各取前两码、3 字前两字首码+第三字前两码、
4 字各取首码、5 字以上前三字首码+末字首码。例如 `你好`→`wqvb`、`计算机`→`ytsm`、
`中华人民共和国`→`kwwl`；两个字的词组如 `工人`→`aaww`（工 aaaa 前两码 + 人 wwww 前两码）。

保存进 `%APPDATA%\PandaWubi\user.tsv`（`编码 <TAB> 内容 <TAB> 权重`，**追加**写入）。
输入法每秒按文件修改时间检查一次，外部窗口或别的进程新加的词会热加载，不用重启。

窗口为什么是独立进程：输入法跑在宿主应用的 UI 线程里，在里面弹模态循环会和 TSF 的焦点/生命周期打架；
窗口用的是 RichEdit 控件，所以本输入法能在里面正常打中文。

**打错再退格的情况**：进词组模式时会读一次"光标前实际还留着的文本"，把最近上屏队列里
已经被删掉的字剔掉（`wubi::TrimCharsByText`，从后往前按子序列匹配）。前提是宿主能把光标位置
报给 TSF；`RichEdit`／记事本这类宿主报的是 0（实测 `ITfRangeACP::GetExtent` 恒为 0），
这种情况下自动剔除会跳过，用 `Del`／`Backspace` 手动删即可。
退格键本身**不能**由输入法声明（声明了宿主会把这一键丢掉、不再删字），所以不走"监听退格"这条路。

端到端（`[C]`=Ctrl+= · `[S]`=Ctrl+Shift+= · `[L]`=← · `[D]`=Del · `[E]`=回车 · `[Q]`=Shift+'）：

```powershell
# 打「工」「人」，再取字入库 -> aaww 工人（← 把新字放最前面，字序不会反）
.\build\tsf-host.exe -send "a w [C][L][L][E]"
.\build\tsf-host.exe -send "aaww "            # -> 工人

# Ctrl+Shift+= 拉起短语窗口（编码/短语由窗口填，保存后热加载）
.\build\tsf-host.exe -send "[S]"
.\dist\panda-phrase.exe                        # 也可以直接手动开
.\build\tsf-host.exe -send "dz "               # -> 窗口里填的那条短语
```

## 快捷键切换后悬浮栏要同步

`Ctrl+Shift+T`（简/繁）、`Ctrl+Shift+P`（标点）以前只改内部状态并落盘，**没有刷新悬浮栏**，
所以栏上还是「简」而实际输出已经是繁体。现在这两条分支末尾都调 `BarSync()`，
栏上的「简/繁」立刻跟着变（和鼠标点栏上的那一格走的是同一条同步逻辑）。

测试宿主新增两个 token：`[T]` = Ctrl+Shift+T、`[P]` = Ctrl+Shift+P，可直接验证。

## 大写锁定（CapsLock）

CapsLock 开着时输入法**整体直通**：字母原样进应用（`ab` → `AB`），不组码、不接管标点。
`Ctrl+=` / `Ctrl+Shift+=` / `Ctrl+Shift+T` 这类热键仍然有效。

## 分号便捷输入的四种走向

按 `;` 进入便捷输入后：

| 下一步 | 行为 |
|---|---|
| 字母 | 转英文单词补全（原逻辑不变） |
| 数字 | 数字转中文大写/小写金额等三种形式（原逻辑不变） |
| 再按 `;` | 输出一个全角分号 `；`（原逻辑不变） |
| **其它可打印键** | 进入**原样记录**：任意字符照记、不限长，回车整段**半角**输出（Backspace 删一个，Esc 取消） |

> 注意：`;` 和 `'` 只有**不带 Shift** 且**已经输过数字**时才是"选数字形式"的键；
> `Shift+;`（冒号）、`Shift+'`（双引号）以及没输数字时的 `;` `'` 都落到"原样记录"里，
> 所以 `;` 之后打冒号能看到 `:`（以前冒号被当成"选形式"的键吃掉，什么都不显示）。

原样记录模式下所有键都归输入法（`WantsKey` 直接返回 true），提示窗显示已记录内容
（超过 48 字只截断显示，提交的是完整缓冲区）；提交时把全角字符转半角
（`FF01–FF5E` 减 0xFEE0，另加 `。、》《「」“”‘’…—` 等）。

实测：`;=abc` + 回车 → `=abc`；`;=123` + 回车 → `=123`；`;=ab` + 两次退格 + 回车 → `=`；
`;=xy` + Esc → 什么都不上屏。

## 提示类候选框（自定义词组 / Z 重复 / 便捷输入）的显示

这些"非组码提示"在组码之外显示，没有 `m_context`，所以编辑会话里取不到光标：
以前那条 `if (haveCaret) ShowAt(...)` 就整段跳过 —— 提示框不出现，可输入法已经进了该模式，
按键全被吞，表现为"按了 Ctrl+= 却什么都没弹出来，接着打字全没了"。

现在：
- 先探测位置：`QueryCaretRect`（GUI 线程插入符）→ 退到**鼠标位置**；
- 编辑会话拿不到光标（没有 context）时，用探测到的位置 `ShowAt` 兜底显示；
- 冷启动直接按 `Ctrl+=`、直接按 `Z`，提示框都会出现在鼠标附近而不是屏幕左上角。

## 自定义短语窗口

`Ctrl+Shift+=` 或设置窗口里打开。**Tab / Shift+Tab 在编码框 → 短语框 → 保存 → 取消 之间循环切换焦点**
（回车=保存，Esc=取消）。

编码框只接受**英文字母**（a–z / A–Z），最多 4 位；数字、标点、汉字都打不进去，
粘贴/输入法带进来的也会被清掉（`wubi::FilterCode`，CLI 里 `panda-cli <dict> codefilter` 有自测）。

## Z 键：最近 4 次上屏 + 版本号

按 `Z`（不带 Shift，且当前不在组码/英文补全/便捷输入中）弹出最多 5 项：

| 序号 | 内容 |
|---|---|
| 1–4 | **最近 4 次上屏的内容，倒序**（1 = 刚打的那次） |
| 5 | `熊猫五笔v1.0.0`（本输入法版本号，方便反馈问题时对照） |

- `空格` / `回车` 选第 1 项；`1`–`5` 选对应项；`Esc` 取消
- 选中的内容直接上屏，并计入"最近上屏"（下次 Z 也能取到）
- 连续重复的内容只记一次

```powershell
.\build\tsf-host.exe -send "a wqvb z2"   # 工 + 你好，Z 列表 [你好, 工, 版本]，选 2 -> 工
.\build\tsf-host.exe -send "a z2"        # 工，Z 列表 [工, 熊猫五笔v1.0.0]，选 2 -> 熊猫五笔v1.0.0
```

> 注：`z` 现在是"菜单键"，所以以 z 开头的编码（dz / sfz 之类）在打完字之后按不出来 ——
> 这是 Z 菜单带来的既有取舍。

## 设置即时生效（不用重启应用）

设置窗口点「保存」（或命令行 `panda-settings.exe /set ...`）后**立即生效，不需要重启任何程序**：会向正在运行的输入法窗口
`PostMessage` 一条注册消息 `PandaWubi.ReloadSettings`；输入法收到后就地重读 `config.ini`、
套用到候选窗外观 / 标点 / 简繁 / 候选个数 / 字体，并立刻刷新正在显示的候选。

```powershell
# 应用开着，改设置，马上生效
.\dist\panda-settings.exe /set CandCount=9
```

日志里能看到：`settings reloaded: punc=1 trad=0 candCount=9 ...`

| 项 | 范围 / 说明 |

## 数据目录（换机/备份）

输入法不自建云端，改为**让用户指定一个目录**，所有"个人数据"都在里面：

| 文件 | 内容 |
|---|---|
| `config.ini` | 全部设置（候选个数/字号/排序/简繁/标点/数据目录指针之外的项……） |
| `user.tsv` | 自定义词组、自定义短语、词频自学习结果 |

- 默认 `%APPDATA%\PandaWubi`；在设置窗口最下面的「数据目录」里**浏览…**选一个目录即可
  （选 OneDrive / 坚果云 / 百度网盘的同步夹最省事，不用自己架服务器）。
- 切换时会**先把旧目录里缺的 `config.ini`、`user.tsv` 复制到新目录**，不会丢东西；
  之后所有读写都走新目录（输入法侧热加载 user.tsv，配置重启后生效）。
- 「打开」直接打开该目录；「默认」一键指回 `%APPDATA%\PandaWubi`。
- 指针本身存在 `HKCU\Software\PandaWubi\DataDir`（机器级，不进同步目录），
  所以换机器后只要在这个窗口里把目录指回云盘那份，设置和自定义词立刻回来。
- 命令行（脚本/免界面）：
  ```powershell
  .\dist\panda-settings.exe /dump                      # 会打印 datadir / userdict
  .\dist\panda-settings.exe /datadir "D:\OneDrive\PandaWubi"
  .\dist\panda-settings.exe /datadir default            # 指回默认
  ```
- 测试/便携：`WUBI_DATA_DIR` 环境变量优先级最高（verify.ps1 用它验证目录切换）。

> 词库本体（`qqwubi86.bin` 等）是**程序数据**，放在 `dist\data`，不进数据目录——
> 换机时拷贝 `dist` 整个目录 + 指回数据目录，就是完整恢复。

## 设置界面（panda-settings.exe）

`dist\panda-settings.exe`（或设置窗口里的「设置」）打开：

- **编译成 GUI 子系统**（`/SUBSYSTEM:WINDOWS`）。以前是控制台程序，被输入法拉起时会先闪一个黑色控制台窗口；
  现在不会了。`/dump`、`/set` 仍可用：stdout 被重定向时直接用继承的句柄，从终端手动运行时才接父进程控制台。
- 版面按 DPI 缩放、用分组框分段（一级简码 / 候选排序 / 输入选项 / 候选窗外观 / 词库），
  统一 微软雅黑 9pt，底部按钮右对齐，窗口居中后一次性显示（先建在屏幕外、摆好位置再 `ShowWindow`，避免闪一下空窗）。
- 保存后弹提示：新设置对之后启动的程序生效。

## 安装包（Inno Setup）

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\build-setup.ps1            # 重新构建 + 打包
powershell -ExecutionPolicy Bypass -File .\tools\build-setup.ps1 -SkipBuild # 只打包现有 dist
```

产物：`dist\PandaWubi-Setup-<版本>.exe`（约 12 MB，LZMA2 压缩自 14 MB 载荷）。

- 脚本：`installer\panda.iss`（由 `tools\build-setup.ps1` 调 `ISCC.exe` 编译，

## 快捷键切换后悬浮栏要同步

## 大写锁定（CapsLock）

CapsLock 开着时输入法**整体直通**：字母原样进应用（`ab` → `AB`），不组码、不接管标点。
`Ctrl+=` / `Ctrl+Shift+=` / `Ctrl+Shift+T` 这类热键仍然有效。

## 分号便捷输入的四种走向

按 `;` 进入便捷输入后：

| 下一步 | 行为 |
|---|---|
| 字母 | 转英文单词补全（原逻辑不变） |
| 数字 | 数字转中文大写/小写金额等三种形式（原逻辑不变） |
| 再按 `;` | 输出一个全角分号 `；`（原逻辑不变） |
| **其它可打印键** | 进入**原样记录**：任意字符照记、不限长，回车整段**半角**输出（Backspace 删一个，Esc 取消） |

> 注意：`;` 和 `'` 只有**不带 Shift** 且**已经输过数字**时才是"选数字形式"的键；
> `Shift+;`（冒号）、`Shift+'`（双引号）以及没输数字时的 `;` `'` 都落到"原样记录"里，
> 所以 `;` 之后打冒号能看到 `:`（以前冒号被当成"选形式"的键吃掉，什么都不显示）。

原样记录模式下所有键都归输入法（`WantsKey` 直接返回 true），提示窗显示已记录内容
（超过 48 字只截断显示，提交的是完整缓冲区）；提交时把全角字符转半角
（`FF01–FF5E` 减 0xFEE0，另加 `。、》《「」“”‘’…—` 等）。

实测：`;=abc` + 回车 → `=abc`；`;=123` + 回车 → `=123`；`;=ab` + 两次退格 + 回车 → `=`；
`;=xy` + Esc → 什么都不上屏。

## 提示类候选框（自定义词组 / Z 重复 / 便捷输入）的显示

这些"非组码提示"在组码之外显示，没有 `m_context`，所以编辑会话里取不到光标：
以前那条 `if (haveCaret) ShowAt(...)` 就整段跳过 —— 提示框不出现，可输入法已经进了该模式，
按键全被吞，表现为"按了 Ctrl+= 却什么都没弹出来，接着打字全没了"。

现在：
- 先探测位置：`QueryCaretRect`（GUI 线程插入符）→ 退到**鼠标位置**；
- 编辑会话拿不到光标（没有 context）时，用探测到的位置 `ShowAt` 兜底显示；
- 冷启动直接按 `Ctrl+=`、直接按 `Z`，提示框都会出现在鼠标附近而不是屏幕左上角。

## 自定义短语窗口

`Ctrl+Shift+=` 打开独立窗口 `panda-phrase.exe`（编码 + 短语两个输入框）：

- **编码框把输入法摘掉了**（`ImmAssociateContextEx(code, nullptr, 0)`）：直接敲 a–z 就是编码，
  不用先按 Shift 切英文；
- 短语框保留输入法，中文可以直接打；
- 之所以要这样：实测在 `panda-phrase.exe` 这个进程里，TSF **不会**把"纯 Shift 单击"转给我们的
  key sink（日志里没有任何 `vk=0x10`），所以 Shift 切英文在短语窗口里本来就不可靠。需要英文时
  用悬浮栏上的「中/英」那一格。

## 顶字上屏（四码满了继续打）

四个码打满之后**再打一个键**时，会把第 1 候选直接上屏、并用这个键开始下一轮组码（五笔习惯）。
实现上有个坑，之前表现为"第五个键被吞掉"：

- 上屏时 `CommitText` 会 `EndComposition` 结束旧的组合串，而 TSF 的
  `OnCompositionTerminated` 回调是**晚一步**才到的；那时如果已经为新码开好了组合串，
  这个迟到回调会把新串一起清掉（连 `composer` 里的新码也 Reset 了），于是第五个键消失、
  候选窗也不出来；
- 现在改成：上屏后**不立刻**开新组合串，只把新码留在 composer 里并刷新候选窗，
  同时用 `m_keepCodeOnTerminate` 标记"这次终止回调别清状态"；
  用户再打一键时才开新组合串。

实测（tsf-host）：`wqvbw` → 上屏「你好」+ 候选窗显示 `w`；继续 `aq` → 编码 `wa`、`waq`，
按键不再丢。

还有一个连带问题要处理：上屏后 pending 的新码**没有组合串**（组合串等下一键才开），
于是空格/数字这些"选字键"会走非组码分支而失效（表现为"空格不上屏"）。
现在在按键处理前补一手：只要 `composer` 里有码却没有组合串，就先 `StartComposition`，
选字键就能正常上屏。实测 `wqvbw` + 空格 → 「你好」+「人」；`wqvbw` + `1` 同样。

## Z 键：最近上屏 + 拼音反查编码

按 `Z` 先弹出「最近上屏的 4 个词（倒序）+ 版本号」，按空格/回车/数字选；此时**继续打字母**就切换成
**拼音反查**模式：

- 打的字母当成拼音（顶部编码框显示正在打的拼音 + 页码，如 `ni  1/45`）；
- 候选里每项是 `汉字 五笔全码`，例如打 `zni` → `1. 你 wqiy`、`2. 呢 knxn` …；
- **支持查词**：拼音连写即可，打 `znihao` → `1. 你好 wqvb`；词的拼音由各字的主读音拼成，
  编码取自码表里该词的码；
- **支持翻页**：`-` 上一页、`=` 下一页（`PageUp`/`PageDown` 也可以），页码显示在顶部框；
- 空格/回车选当前页第 1 个，数字选当前页第 N 个，`Esc` 退出，`Backspace` 改拼音；
- 同一拼音内按词频排序（词频取自主码表里单字的权重），常见字在前；繁体异体字已过滤。

数据文件：`data\pinyin.tsv`（`拼音<TAB>字<TAB>五笔全码`），由
`tools\build-pinyin.ps1` 从 Rime 的 `luna_pinyin.dict.yaml`（小狼毫自带）+ `data\char_fullcodes.tsv`
+ 主码表权重生成。没有这个文件时，Z 只剩「最近上屏」功能，反查自动降级。

```
powershell -ExecutionPolicy Bypass -File .\tools\build-pinyin.ps1
```

## 悬浮状态栏（🐼 中 简 ⚙）

桌面右下角那条自绘状态栏由 `src/tsf/wubi_bar.cpp` 实现，**每个进程最多一条**：

- 进程内唯一：TSF 会为每个线程各建一个 `CTextService` 实例，实例共用一条栏，实例计数归零才销毁窗口；
- 只在宿主进程处于前台时显示（线程焦点回调立即响应，500ms 前台自检兜底），所以切走应用后不会留下一条悬在别人窗口上；
- 最左边是产品 Logo（和输入法指示器同一个 `panda.ico`），这块也是拖动区；
- 状态栏点击回到"当前拥有者"实例：`中/英`、`简/繁`、`⚙`（打开设置）三项，都走同一份 `config.ini`；
- **右键菜单**：中文输入 / 简繁输出 / **主题 ▸**（熊猫·狸花猫·中华田园犬·丹顶鹤，当前项打勾）/ 设置… / 版本号。
  在菜单里切主题等价于改 `Theme`：本进程立刻生效，并给其它进程的悬浮栏/候选窗广播"重读配置"。\n- 原来的「，。」（全角/半角 · 中文标点）那一格**已移除**：需要半角时切到英文模式即可，\n  中文标点仍可在设置窗口或 `Ctrl+Shift+P` 里调整。\n- 右键菜单：中文输入 / 简繁输出 / 设置… / 版本号。\n- **全系统只显示一条**：每份 DLL 都会在自己的宿主进程里建一个栏窗口（不可见地待命），
  但只有"前台窗口属于本进程"的那一份才显示；它显示时会通知其它进程的栏让位
  （`PandaWubi.BarYield` 消息 + 直接 `ShowWindow(SW_HIDE)`，绝不跨进程 `DestroyWindow`），
  并且每 ~2.5 秒再压一次，连"对方计时器已经停了"的僵尸栏也能收掉。
  典型表现：切到哪个应用，就只剩那个应用的那一条栏。
- 悬浮栏位置会先夹到当前屏幕工作区内：config.ini 里的旧坐标可能来自别的分辨率或已拔掉的显示器\n  （实测存过 6136,3091，整条栏跑到屏幕外），现在会自动回落到右下角。

回归测试（不需要注册、不依赖 HKLM）：


`bar-singleton-test` 断言：激活前 0 条 → 1 个实例 1 条 → **2 个实例仍 1 条** → 部分释放仍 1 条 →
全部释放 0 条 → 非前台时必须隐藏。旧实现会在第 3 步变成 2 条、并在切走应用后保持可见。
`tools\verify.ps1` 已包含这三项检查。

## 组码不上屏（编码只在候选窗里显示）

组码阶段的字母**不会写进文档**，编码只显示在候选窗顶部的小框里；汉字上屏后文档里直接出现汉字，
不存在"先出现字母再被替换"的过程。

```powershell
.\build\tsf-host.exe -send "wqvb"     # 文档里是空的（编码 wqvb 只在候选窗顶部）
.\build\tsf-host.exe -send "wqvb "    # -> 你好
.\build\tsf-host.exe -send "wqvbx"    # -> 你好（顶字上屏后继续组码 x）
```

英文补全模式仍然把字母显示在文档里——那本来就是最终要输出的内容。

**任何一个候选都没匹配到时，编码框仍然保留**（不再是整块消失）：屏幕上一眼能看到刚敲的码，
不会出现"还在组码却什么都没有"的困惑。例如 `xxqq`（词库里没有）：

```powershell
.\build\tsf-host.exe -send "xxqq"     # 文档空，候选框只剩顶部编码框显示 xxqq
```

空码（一个候选都没有）时不会卡住，下面几种操作都会**直接把空码清掉**：

| 操作 | 结果 |
|---|---|
| `回车` / `空格` | 空码丢弃，不写任何文字 |
| 继续打字母 | 丢掉旧码，用这一键重新组码（`xxqqa` → 工） |
| 打标点 | 丢掉空码，只输出这个标点（`xxqq,` → ，） |
| `退格` | 照常逐位删码，删到有候选就恢复 |

## 中文词语自动学习（会话级）

连续上屏**单个汉字**时，输入法把"相邻两字""相邻三字"拼成候选词，按五笔 2/3 字取码规则算码
（2 字：各取前两码；3 字：1+1+2），放进**本进程的会话表**：

- 候选中这些词**排在最末**（码完全相同才出现），永远不挤占正常候选；
- **不落盘**：进程结束就全忘（等于"临时记住我刚打过的组合"）；
- 只有你**真的选中**它（数字键或鼠标点它）才正式写进 `user.tsv`，从此算普通用户词。

**按键退格/删除过这个字，刚学的那条词会一起撤掉**（日志 `session undo: 一地`）——
这条词本来就是你打字过程中的副产品，删掉字就是"我不想要"，不该留在候选里。

实测：打「一」再打「地」→ 日志 `session word: 一地 (code=ggfb)`；再打 `ggfb` → `天王老子` 仍第 1、
`一地` 第 2，按 `2` 上屏并在 `user.tsv` 里出现 `ggfb<TAB>一地`；不选它则 `user.tsv` 不变；
打「一」「地」「一」会同时学出 `地一`(fbgg) 与 `一地一`(gfgg)；
打「一」「地」「一」「地」还会学出 `地一地`(fgfb) 和 4 字的 `一地一地`(gfgf)，
打 `gfgf` 时 4 个正常候选不动、`一地一地` 排第 5，按 `5` 选它就落盘。

## 英文单词补全（Shift+字母）

`Shift+字母` 进入补全模式后，**大小写照抄键盘输入**（Shift 与 CapsLock 相异即为大写），
不再一律当小写：

| 实际按键 | 候选/上屏 |
|---|---|
| `a` `b` | `about` |
| `Shift+A` `b` | `About`（单个大写字母 = 首字母大写） |
| `Shift+A` `Shift+B`（或开 CapsLock） | `ABOUT`（连续大写 = 整词大写） |
| `Shift+A` `b` `Shift+O` | `AbOut`（逐字保留） |

规则实现在 `wubi::ApplyCase()`（`src/engine/wubi_english.cpp`），纯函数、可单测：
`panda-cli <dict> engcase` 跑 9 组用例，`tools\verify.ps1` 里对应「大小写照抄输入」一项。

候选窗**顶部小框显示的就是你实际敲的样子**（含大小写），不再显示上一段中文组码：

| 键 | 效果 |
|---|---|
| `空格` | 选第 1 个候选补全，并补一个空格（`Ab ` → `About `） |
| `回车` | **不补全，原样上屏**顶部小框里的内容（`AbC⏎` → `AbC`） |
| `1`–`9` | 选第 N 个候选（同样补空格） |
| `退格` | 删掉一个字母；删空即退出英文模式 |
| `Esc` | 全部取消，什么都不上屏 |

上屏/取消后顶部小框会清空，不会残留到下一次。

**没匹配到任何单词时，候选框不会消失**，而是只剩顶部小框显示当前输入（不再画翻页箭头和熊猫装饰），
这样你随时能看清自己敲了什么；一旦继续敲出匹配的字母，候选行会重新出现。

端到端（真实键盘事件，会短暂抢占前台）：
```powershell
.\build\tsf-host.exe -send "Ab "     # -> About
.\build\tsf-host.exe -send "AB "     # -> ABOUT
.\build\tsf-host.exe -send "wqvb "   # -> 你好（中文不受影响）
.\build\tsf-host.exe -send "AbC[E]"  # -> AbC（回车原样上屏，不补全）
```
